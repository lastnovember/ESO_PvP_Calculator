'''Craftable Sets''' are [[ON:Sets|sets]] which can be crafted by players pursuing any of the equipment crafting lines: [[ON:Blacksmithing|Blacksmithing]], [[ON:Clothing|Clothing]], [[ON:Jewelry Crafting|Jewelry Crafting]], and [[ON:Woodworking|Woodworking]]. Each craftable set has a [[ON:Crafting Sites|crafting site]], and those in the Alliance zones have one per Alliance. Each craftable set requires a certain number of [[ON:Traits#Research|researched]] [[ON:Traits|traits]] in an item for it to be crafted in that set. For example, to craft an axe in the [[ON:Hunding's Rage|Hunding's Rage]] set, one would need six traits researched for axes. One could also craft a Death's Wind axe which would only require two traits.

There are currently {{PAGESINCATEGORY:Online-Sets with Crafting Site(s)}} craftable sets available.

==Bonuses Progression==
Many sets have a bonus specified as a range which depends on item level and quality. These ranges are fairly linear, with the values listed in the tables below. One exception of note is that Level 50 and {{ESO Champion|10}} are identical, up to Superior quality (items will behave more or less the same apart from the enchantment levels that can be applied). The stat increase for Champion Ranks that are a multiple of 20 (with the exception of {{ESO Champion|160}}) are larger than those that aren't, so upgrading only when hitting such levels may make economical sense.

Each "Bonus Type" tends to use the same range, so any new site items you find can be assumed to use the same ranges. The ranges listed below are for crafted items.  Found set items may be found at levels between these, and will have similar values.

In Update 6 the attributes were overhauled and the values below changed significantly. These values were adjusted again in Update 15.
