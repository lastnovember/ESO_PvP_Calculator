# Update 50 is Now Available on the Public Test Server

Source: https://www.elderscrollsonline.com/en-us/news/post/69713
Tier: combat-news
Published: unknown

Test Update 50’s content and changes, including PvP
 Veterancy, Challenge difficulty, Werewolf updates, new story content, and much
 more, on the Public Test Server.
The Public Test Server (PTS) has been updated! The features
 arriving with Update 50, which will be released over the course of the
 remainder of Season Zero and into Season One, are now available for testing,
 and you can access them via the PC/Mac ESO launcher.
You can now take an early look at the PvP Veterancy system,
 new Challenge difficulty settings, updated Werewolf character models and skill
 line, new story content, Class Mastery skill lines, the first Dynamic World
 Events, and more!
Note that some Season One content will be turned on over the
 course of the PTS process. Story content for the Thieves Guild as well as the
 new Favors system will be activated approximately a day after PTS opens, with
 further story content focused on the Daedric Prince Sheogorath activating in a
 future update of this Public Test Server cycle—keep an eye on the official ESO
 website for details!
To access the PTS environment, go to the Settings menu
 within the PC/Mac ESO launcher by toggling the “Show Public Test Environment”
 option. You can then download and access the test environment. Don’t forget to
 leave feedback and report any bugs you come across by typing “/feedback” or
 “/bug” in chat.
