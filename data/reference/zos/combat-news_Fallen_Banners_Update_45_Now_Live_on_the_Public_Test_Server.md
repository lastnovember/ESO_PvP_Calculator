# Fallen Banners & Update 45 Now Live on the Public Test Server

Source: https://www.elderscrollsonline.com/en-us/news/post/67429
Tier: combat-news
Published: unknown

Dive into 2025’s new adventures by helping test Fallen
 Banners and Update 45 on the PC/Mac Public Test Server!
The Public Test Server (PTS) has now been updated to include
 both the upcoming
Fallen Banners
dungeon pack and the Update 45
 base-game patch, giving you access to two new dungeons, refreshed starter
 zones, the features for the Cyrodiil Champions Test campaign, and a host of
 quality-of-life improvements, including improvements to Craft (green) Champion
 points!
To access the PTS, go to the Settings menu within the PC/Mac
ESO
launcher by toggling the “Show Public Test Environment” option. You can
 then download and access the game client, which also grants you immediate
 access to the
Fallen Banners
dungeons to test. As a result, you
 shouldn't need to purchase it on the test server's Crown Store. Don’t forget to
 leave feedback and report any bugs you come across by typing “/feedback” or
 “/bug” in chat. If you want to learn about the features coming in Update 45 or
 anything else to do with the patch, be sure to check out the
preview blog
and
PTS Patch Notes
on the
ESO
forums.
