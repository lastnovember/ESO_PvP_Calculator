# Seasons of the Worm Cult Part 1 & Update 46 Now Live on the Public Test Server

Source: https://www.elderscrollsonline.com/en-us/news/post/67889
Tier: combat-news
Published: unknown

Squash the Worm Cult’s machinations and game bugs alike
 by helping test the new update and content on the PC/Mac Public Test Server!
The Public Test Server (PTS) has now been updated to include
 both the upcoming Seasons of the Worm Cult Part 1 content and the Update 46
 base-game patch, giving you access to a new storyline, Western Solstice, subclassing,
 and much more.
To access the PTS, go to the Settings menu within the PC/Mac
ESO
launcher by toggling the “Show Public Test Environment” option. You
 can then download and access the game client. Don’t forget to leave feedback
 and report any bugs you come across by typing “/feedback” or “/bug” in chat.
If you want to learn about the features coming in Update 46
 or anything else to do with the patch, be sure to check out the
preview blog
and
PTS Patch Notes
on the
ESO
forums.
