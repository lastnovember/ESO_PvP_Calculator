# Update 47 and Feast of Shadows Are Now Available on the Public Test Server

Source: https://www.elderscrollsonline.com/en-us/news/post/68409
Tier: combat-news
Published: unknown

Help test new features and dungeons coming to the game in
 Update 47 by playing on the PTS!
The Public Test Server (PTS) has now been updated to include
 both the upcoming
Feast of Shadows
dungeon pack and the Update 47
 base-game patch, giving you access to two new dungeons, mount swimming,
 stackable survey reports, and more! This is also
 your first chance to help us test the first stages of the upcoming (Q4)
 Writhing Wall event.
To access the PTS, go to the Settings menu within the
 PC/Mac
ESO
launcher by toggling the “Show Public Test
 Environment” option. You can then download and access the game client. Don’t
 forget to leave feedback and report any bugs you come across by typing
 “/feedback” or “/bug” in chat.
If you want to learn about the features coming in Update 47
 or anything else to do with the patch, be sure to check out the
preview blog
and
PTS Patch Notes
on the
ESO
forums.
