# Update 43 Is Now Available on the PC/Mac Public Test Server

Source: https://www.elderscrollsonline.com/en-us/news/post/66365
Tier: combat-news
Published: unknown

Test out new quality-of-life features, including an
 all-new system to tour player homes across Tamriel, in the Update 43 base-game
 patch on the PC/Mac Public Test Server!
Update 43 is ready for your testing and feedback! The Public
 Test Server (PTS) has now been updated to include Update 43, giving you access
 to Home Tours, additions to Infinite Archive, and more. To access the PTS, go
 to the Settings menu within the PC/Mac
ESO
launcher by toggling the “Show
 Public Test Environment” option. You can then download and access the game
 client. Don’t forget to leave feedback and report any bugs you come across by
 typing “/feedback” or “/bug” in chat.
If you want to learn about the features coming in Update 43
 or anything else to do with the patch, be sure to check out our recent
preview livestream
and
PTS Patch Notes
on the
ESO
forums.
