# Test ESO’s Upcoming Adventures with Update 51 on the PTS

Source: https://www.elderscrollsonline.com/en-us/news/post/70247
Tier: combat-news
Published: unknown

Update 51 is now live on the PC/Mac Public Test Server,
 and you can help us put it through its paces!
The PC/Mac Public Test Server is now live with the Update 51
 base-game patch. This PTS cycle will introduce content from both
Season One
and
 Season Two (currently scheduled for October), and this is your chance to help
 us test those upcoming adventures before they are released!
Here’s the new features included in this latest test cycle:
Now live on PTS
Season One’s Rumors system
Season One’s High Seas of Tamriel event
Season One’s Player Experience Improvements
Arriving with PTS2 on August 10
Season One’s Nowhere Vault challenge
Arriving with PTS3 on August 17
Season Two’s Solo Dungeons
…and more!
To access the PTS environment, visit the Settings menu
 within the PC/Mac
ESO
launcher by toggling the “Show Public Test
 Environment” option. You can then download and access the test environment.
 Don’t forget to leave feedback and report any bugs you come across by typing
 “/feedback” or “/bug” in chat.
For more about Update 51, please read the PTS Patch Notes on
 the
official
 ESO forums
.
