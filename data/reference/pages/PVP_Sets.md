# Online:PVP Sets

Source: https://en.uesp.net/wiki/Online:PVP_Sets
Fetched: 2026-09-12
License: CC BY-SA, UESP

PVP Sets are sets of armor, weapons and jewelry that can be obtained from Cyrodiil, the Imperial City or Battlegrounds. Items of these sets can usually be bought using Alliance Points or Tel Var stones.

## Alliance War Sets
The following sets can be obtained from Cyrodiil town quests, as a reward for completing delves and dolmens throughout Cyrodiil, from completing Board Missions, from each alliance-aligned town's quartermaster using Alliance Points, and from the Alliance Quartermasters, also using Alliance Points. For information on the individual items in each set, see their respective pages.

Wrath of the Imperium

### Elite Gear Sets
The following sets were formerly obtained "Rewards for the Worthy", but can now be obtained from Cyrodiil town quests, as a reward for completing delves and dolmens throughout Cyrodiil, from completing Board Missions, from each alliance-aligned town's quartermaster using Alliance Points, and from the Alliance Quartermasters, also using Alliance Points. For information on the individual items in each set, see their respective pages.

Warrior's Fury

## Battlegrounds Sets
The following sets can be obtained from competing in the Battlegrounds. For information on the individual items in each set, see their respective pages.

The following sets can be obtained from the Rewards for the Worthy.

## Tel Var Sets
The following sets can only be obtained from the Tel Var Merchants within the Imperial City. Tel Var Armorers sell unidentified pieces of gear, while Tel Var Grand Armorers sell curated items. For information on the individual items in each set, see their respective pages.
