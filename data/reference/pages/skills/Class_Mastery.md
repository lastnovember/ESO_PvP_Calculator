# Online:Class Mastery

Source: https://en.uesp.net/wiki/Online:Class_Mastery
License: CC BY-SA, UESP

Class Mastery is a skill system introduced with Update 50 that provides passive skill lines for each of the seven Player Classes. Each class will have five different passive skills and for each character you will be able to pick two of them.

For a character to make use of the system, they must meet the following prerequisites:
- Reach Level 50 in all three of the character's class skill lines.
- Not using the Subclassing system.
