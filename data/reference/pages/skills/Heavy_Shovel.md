The Heavy Shovel is a tool used when excavating an antiquity that digs up 1 layer of dirt in a 3x3 area. It can only be used once you have at least 2 intuition (which is generated from using the Hand Brush two times). It is most useful when you have already located the exact or approximate location of the antiquity using the Augur skill, as it allows you to clear large patches of dirt in one go. Note that if the 3x3 area contains dirt at different layers, only the dirt at the center tile and dirt directly connected to the center tile at the same height will be dug up. Therefore, for efficient use, it is recommended to first ensure all dirt in the 3x3 area is at the same height using the Hand Brush tool.

Upon unlocking the second upgrade, the Heavy Shovel will occasionally not consume any Intuition. This allows it to be used several times in a row, therefore greatly shortening the time taken to excavate an antiquity and allowing more time to search for bonus loot.

If you have the second Hand Brush upgrade, it is possible to store up to 4 intuition and therefore use the Heavy Shovel to dig two layers down in one go. It thus becomes important to check that you are not already digging up the lowest layer, otherwise you will damage the antiquity. Higher level antiquities are especially delicate and can be damaged in one hit.
