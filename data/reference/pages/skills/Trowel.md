The Trowel is a tool that digs up 3 layers of dirt in an excavation. It can only be used once you have at least 2 intuition (which is generated from using the Hand Brush two times). Care should be taken when using the Trowel since it is possible to damage the antiquity by digging too far down.

Upon unlocking the second upgrade, the Trowel can be used to trigger a detonation. This requires that you form a path between all fissures which you wish to use to trigger the explosion. A path between fissures is formed by making sure that all the dirt connecting the fissures is at the same level. Note that if the antiquity is located anywhere within the path of the detonation, it will be immediately destroyed and you will have to start the excavation again. This skill is therefore best used once you have already finished digging up the antiquity and are hunting for bonus loot.

If you have the second Hand Brush upgrade, it is possible to store up to 4 intuition and therefore use the trowel to dig six layers down in one go. This makes it even more important to calculate the layers of dirt remaining and so avoid damaging the antiquity. Higher level antiquities are especially delicate and can be damaged in one hit.
