# Online:Subclassing

Source: https://en.uesp.net/wiki/Online:Subclassing
License: CC BY-SA, UESP

Subclassing is a system that was released in the base game Update 46. It allows a player to customize their character by replacing up to two of their class' skill lines with those from other classes. In order to use subclassing, you must first have at least one level 50 character; once this criterion is met, the quest A Study in Discipline must be completed on each character whose base class skill lines you wish to change.

While base class skill lines are levelled separately on individual characters, progress in sub-classed skill lines is shared across all characters on your account. You can have up to three unlevelled sub-class skill lines at a time; once a subclass skill has been fully levelled, it is considered 'mastered' in the same way that base class skills can be mastered. A subclassed skill line gains access to all skills and passives in the same way as base class skill lines, although each stage costs two skill points instead of one.
