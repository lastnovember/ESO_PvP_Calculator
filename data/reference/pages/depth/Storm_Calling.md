# Online:Storm Calling

Source: https://en.uesp.net/wiki/Online:Storm_Calling
License: CC BY-SA, UESP

Storm Calling is one of three class skill lines available to Sorcerer characters. It can be learned by other classes via subclassing. Abilities in this line focus on dealing magical damage.

## Skill Perks
The Storm Calling skill line is immediately available to all Sorcerers, and is leveled up by earning experience while Storm Calling skills are slotted. Skills include:
