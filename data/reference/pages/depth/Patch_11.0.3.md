The Elder Scrolls Online v11.0.3 kicks off week 4 of the PTS Cycle. The main focus of this week's PTS update is to address combat changes for both classes and the upcoming trials sets. Additionally, we have a variety of fixes and improvements to the Seasons of the Worm Cult, Part 1 content. There are more adjustments and fixes for Ossein Cage, and overall quest fixes.

There are also more base game adjustments, including added improvements to the Hero's Return efforts. Overall, you will find fixes for Fallen Banners, High Isle, Solstice, and Base Game content in this week's patch notes.

We have copied all PC EU characters for usage during week four of PTS. As always, feel free to provide feedback on PTS v11.0.3 through our feedback and bug threads, located here. The update is 717.88MB.

## New Features / Updates / Big Changes

### Hero's Return
- We updated the Hero's Return adventure to be an official quest.
- Now, when you arrive in the Aetherian Archive after accepting Vanus Galerion's invitation from the Hero's Return pop-up, you will have to accept the quest from Vanus to be able to continue through the experience.
- [Developer Comment] (Spoiler): We found some of you could feel a bit lost without the more traditional quest guidance about where to go next, so we have smoothed out this experience and helped provide a cleaner flow to help players feel like they are on the right path.
- Damage shield visuals have been updated in the encounters and provide better reinforcement when following the tutorial prompts. You can see when progress is being made in the encounters.
- Adjusted the timing of the ability bar overrides and sprint tutorial in the Hero's Return adventure to provide a window for you to set your own skills if desired.
- You now need to complete 2 quests in the Hero's Return Campaign titled "Ride Out to Adventure."
- Resolved an issue where the Hero's Return Campaign "Better Together" would not reward the second milestone reward when claiming it.
- Improved the behavior of the Hero's Return Announcement panels in older tutorial zones (for the rare characters still present in those zones), to reduce UI distractions until you're done with the tutorial, similar to Soul Shriven in the Coldharbour tutorial.
- Updated the Rededication help entry to cover the following:
- Various rededication shrine cultural names
- A few more example shrine locations
- Respec scroll behavior
- Bahtra at-Hunding's rededication services
- Corrected previously incorrect shrine setup in the Solstice Cathedral.

## Known Issues

### Attack Animations
- Though many more animations have been fixed from the previous PTS, some abilities still contain extraneous movement, particularly in the extremities (hands, tails, weapons, feet, etc.) which looks like twitching, shaking, or overly abrupt movements.
- If casting while running diagonally, the character can be pointing up to 45 degrees away from the target (most obvious with ranged attacks). This is a more exaggerated version of an issue that has always existed. The final fix will keep you facing your target.
