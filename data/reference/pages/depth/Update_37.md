Update 37 is the thirtyseventh major update patch for The Elder Scrolls Online, and will introduce the Scribes of Fate DLC. It became available on the PC/Mac Public Test Server (PTS) on January 30, 2023. It will be the first update since Greymoor that did not release on Stadia.

It may refer to:
- Patch 8.3.5 for PC/Mac.
- Patch 2.?? for PS4/1.15 for PlayStation 5.
- Patch for Xbox One.

### New Features / Updates / Big Changes
