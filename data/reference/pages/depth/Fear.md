# Online:Fear

Source: https://en.uesp.net/wiki/Online:Fear
License: CC BY-SA, UESP

Fear is a debilitating effect which prevents a target from attacking, causing them to run away or cower instead which is identical to Stunning. You can get out of it with a Break Free action. Fear will not cause targets to run off cliffs, but they may end up running into flames or other AoE effects.
