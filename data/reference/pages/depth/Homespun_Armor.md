# Online:Homespun Armor

Source: https://en.uesp.net/wiki/Online:Homespun_Armor
License: CC BY-SA, UESP

This is a listing of all standard Homespun Armor in the game. These can be used with the Light Armor skill. Homespun armor can be crafted via Clothing from Jute obtained by refining raw samples collected from Jute plants. The listed armor values assume that the character is CP160; lower level characters may see higher values.
