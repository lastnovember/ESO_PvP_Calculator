# Online:Group Events

Source: https://en.uesp.net/wiki/Online:Group_Events
License: CC BY-SA, UESP

true Update 12
This page lists all the Group Events in Elder Scrolls Online. Five of each type were scattered throughout Adventure Zones and offered a challenge for groups of four or more. Completing the event would reward participants with a loot chest and a fifteen minute buff. They did not award any Completion XP for doing so.

These Group Event locations were recategorized as Group Bosses in Update 12, with each one being given a unique name. Additionally, the buff now applies for one hour.
