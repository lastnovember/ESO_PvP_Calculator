# Online:Rawhide Armor

Source: https://en.uesp.net/wiki/Online:Rawhide_Armor
License: CC BY-SA, UESP

This is a listing of all standard Rawhide Armor in the game. These can be used with the Medium Armor skill. Rawhide armor can be crafted via Clothing from Rawhide. The listed armor values assume that the character is CP160; lower level characters may see higher values.
