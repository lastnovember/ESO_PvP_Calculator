## Quick Walkthrough
# Talk to Captain Gaercroft.
# Search for the missing scouts.
# Find the wyrd camp.
# Destroy the Reachmen's markers.
# Find and kill Duraeg.
# Destroy the seeds.
# Return to Captain Gaercroft.

## Detailed Walkthrough

## Notes
- Hatmi won't exist in the chapel before starting the quest.
- The objective completion only occurs if stepping very close to Hatmi.
- While the house can be accessed beforehand, Duraeg and Isabeth won't exist inside before starting the quest and reaching the related objective.
- Using the poultice will turn all enemies to Neutral. It wears off if you attack or leave Northglen however.
