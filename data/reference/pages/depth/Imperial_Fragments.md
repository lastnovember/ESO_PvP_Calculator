# Online:Imperial Fragments

Source: https://en.uesp.net/wiki/Online:Imperial_Fragments
License: CC BY-SA, UESP

Imperial Fragments are an account-wide currency earned within the Imperial City. Unlike with Tel Var Stones, you will not lose any of this currency upon death.

## Sources
You earn Imperial Fragments from the following:
- Killing enemies in the Imperial City.
- From treasure chestsplain

## Using Imperial Fragments
This currency can be used by speaking to the vendor Tur found within the Trophy Vaults. At each location she will have different wares.

## Notes
- Prior to Update 44 Imperial Keys and Imperial Key Fragments were the currency used for accessing the Trophy Vaults in the Imperial City. With the release of the update, all the Imperial Keys and Fragments currency was converted to Imperial Fragments.
