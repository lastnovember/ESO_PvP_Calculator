# Online:Hemorrhaging

Source: https://en.uesp.net/wiki/Online:Hemorrhaging
License: CC BY-SA, UESP

Hemorrhaging The Hemorrhaging is a status effect applied by dealing Bleed Damage. It deals bleed damage over time, stacking up to 3 times. Each stack increases the damage by 25%. The Hemorrhaging effect lasts 4 seconds and ticks every 2 seconds. This status effect can be removed with a Cleansing effect. This status effect is the only one that cannot be applied via a weapon glyph.
