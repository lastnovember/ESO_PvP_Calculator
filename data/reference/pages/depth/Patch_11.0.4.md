May 12, 2025([https://forums.elderscrollsonline.com/en/discussion/677720/pts-patch-notes-v11-0-4 forum post])

The Elder Scrolls Online v11.0.4 introduces bug fixes and improvements for Seasons of the Worm Cult, Part One and Base Game zones as we enter the last week of PTS. There are also minor fixes for Blackwood, Clockwork City, Gold Road, and Necrom content.

Additionally, there are very minor itemization changes and a slight tweak to Nightblade's Grim Focus.

The main focus of this update is focusing on Trial, Dungeon, and Zone fixes for Season of the Worm Cult, Part One. We also have base game systems like Hero's Return that have gotten some improvements.

One major thing to note: changes to the animation system to reduce memory usage have been reverted for update 46. These need more testing and refinement. We are taking the feedback made during this test cycle to continue improvements.

As we close out PTS testing for Update 45, please review the full list of patch notes below. If you have feedback on PTS v11.0.4, make sure to provide it in our feedback and bug threads, located here. We look forward to your feedback.

## New Features / Updates / Big Changes

### Hero's Return
- If your skill bar is temporarily overridden, you can no longer remove those overrides earlier than intended.
- While on "The Rogue Mage" quest step, if you leave the area and return before it shuts down, you should be on the proper quest step and able to continue.
- Vanus Galerion had some mismatched audio/dialog, as well as one voice line that was not playing. These have all been fixed.
- We adjusted Max Health and Power stats for enemies to better align with other game scaling.

## Known Issues

### Attack Animations
- Though many more animations have been fixed from the previous PTS, some abilities still contain extraneous movement, particularly in the extremities (hands, tails, weapons, feet, etc.) which looks like twitching, shaking, or overly abrupt movements.
- If casting while running diagonally, the character can be pointing up to 45 degrees away from the target (most obvious with ranged attacks). This is a more exaggerated version of an issue that has always existed. The final fix will keep you facing your target.

## Combat & Gameplay

### Combat & Abilities

#### Alliance War
- Assault
- Vigor
- Echoing Vigor: We reduced the duration of some of the visuals for this ability, so they do not persist and stack when multi-casting.

#### Classes
- Nightblade
- Assassination
- Grim Focus
- Merciless Resolve: This ability should no longer bypass certain defensive bonuses and functions, such as Crystallized Shield.

### Itemization & Item Sets

#### Mythic Items
- Mad God's Dancing Shoes
- The stamina and ultimate gain from these sets have a small delay to better match up with the visuals.
- The telegraph for the forward-facing attack will now appear yellow to the caster. This will help them aim while not confusing the ability as an enemy's attack.

#### Trial Sets
- Dolorous Arena
- The debuff visual effects should no longer remain on the enemy after the debuff ended.
- Kazpian's Cruel Signet: This set can now apply damage once every second, up from once every half second. Reduced the damage of the proc by ~29%. We also raised the increase to your total damage per sword active to 2% per, up from 1%.
- [Developer Comment] (Spoiler): We're adjusting this set so it has less variance in its power between multi-proc ability types such as Fatecarver vs Whirlwind. As such we're going to put slightly more power into this set's potential damage increase, while also reducing the damage per proc so it feels a bit more focused as a damage enhancer.
- Recovery Convergence: Removed the animation from the synergy granted from this set.
