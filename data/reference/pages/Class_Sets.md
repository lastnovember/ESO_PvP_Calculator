# Online:Class Sets

Source: https://en.uesp.net/wiki/Online:Class_Sets
Fetched: 2026-09-12
License: CC BY-SA, UESP

Class Sets are sets that provide players of the specified class with various bonuses when items of the same set are equipped simultaneously. Players not of the class the set is for cannot equip that set.
