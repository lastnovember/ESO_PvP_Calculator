# Online:Perfected Crushing Wall

Source: https://en.uesp.net/wiki/Online:Perfected_Crushing_Wall
License: CC BY-SA, UESP

Perfected Crushing Wall is a Perfected Maelstrom Weapons item set found in veteran Maelstrom Arena. It cannot be crafted. Pieces are Maelstrom style. The non-perfected version of this set can be looted on normal difficulty.

### Bonuses

2 perfected items: Adds 27-1190 Offensive Penetration
2 items: Increases the damage Wall of Elements deals by 29-1250.

### Pieces
The set consists of destruction staves of all three types.

### Notes
- While the description states that 2 items are required, this is because staves are 2-handed weapons, and thus count as 2 items by themselves, so only 1 item is actually needed.
