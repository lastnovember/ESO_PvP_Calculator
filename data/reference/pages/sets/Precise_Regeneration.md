# Online:Precise Regeneration

Source: https://en.uesp.net/wiki/Online:Precise_Regeneration
License: CC BY-SA, UESP

Precise Regeneration is a Maelstrom Weapons item set found in normal Maelstrom Arena. It cannot be crafted. Pieces are Maelstrom style. The perfected version of this set can be looted on veteran difficulty.

### Bonuses

2 items: When your Regeneration critically strikes, you restore 12-558 Magicka. This effect cannot occur from simultaneous critical strikes.

### Pieces
The set consists of a restoration staff.

### Notes
- While the description states that 2 items are required, this is because staves are 2-handed weapons, and thus count as 2 items by themselves, so only 1 item is actually needed.
