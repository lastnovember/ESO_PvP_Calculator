# Online:Armor of the Code

Source: https://en.uesp.net/wiki/Online:Armor_of_the_Code
License: CC BY-SA, UESP

Armor of the Code was an item set found at one time in the data files, but which has since been disabled. This was a craftable set, as attuned crafting stations for it can still be found in the game data, though there were never crafting stations available in the game, so attuning a station to them is impossible. It's possible it was created only for testing purposes by the developers. The unusual aspect of having the unique enchantment from just 1 item instead of all 5 suggests that this was never intended to be seen in the actual game.

### Bonuses

1 item: Increase your Critical Chance against targets with a lower % of health than you by 47-2051.
2 items: Adds 25-1096 Maximum Magicka
3 items: Adds 3-129 Magicka Recovery
4 items: Adds 25-1096 Maximum Magicka
