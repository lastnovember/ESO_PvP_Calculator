# Online:Perfected Thunderous Volley

Source: https://en.uesp.net/wiki/Online:Perfected_Thunderous_Volley
License: CC BY-SA, UESP

Perfected Thunderous Volley is a Perfected Maelstrom Weapons item set found in veteran Maelstrom Arena. It cannot be crafted. Pieces are Maelstrom style. The non-perfected version of this set can be looted on normal difficulty.

### Bonuses

2 perfected items: Adds 12-526 Critical Chance
2 items: Increases the damage Volley deals by 10-430 each tick. This bonus increases by 4-191 every time Volley ticks, up to a maximum of 8 times.

### Pieces
The set consists of a Bow.

### Notes
- While the description states that 2 items are required, this is because bows are 2-handed weapons, and thus count as 2 items by themselves, so only 1 item is actually needed.
