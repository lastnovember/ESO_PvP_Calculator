# Online:Piercing Spray

Source: https://en.uesp.net/wiki/Online:Piercing_Spray
License: CC BY-SA, UESP

Piercing Spray is an Asylum Weapons item set which drops in normal Asylum Sanctorium after defeating Saint Olms the Just. It cannot be crafted. Pieces are Asylum Style. The perfected version of this set can be looted on veteran difficulty.

### Bonuses

2 items: When you deal damage with Arrow Spray, you cause enemies hit to have 153-6600 less Armor against Bow attacks for 10 seconds.

### Pieces
The set consists of a Bow.

### Notes
- While the description states that 2 items are required, this is because bows are 2-handed weapons, and thus count as 2 items by themselves, so only 1 item is actually needed.
