# Online:Disciplined Slash

Source: https://en.uesp.net/wiki/Online:Disciplined_Slash
License: CC BY-SA, UESP

Disciplined Slash is an Asylum Weapons item set which drops in normal Asylum Sanctorium after defeating Saint Olms the Just. It cannot be crafted. Pieces are Asylum Style. The perfected version of this set can be looted on veteran difficulty.

### Bonuses

2 items: When you deal damage with Reverse Slash, you generate up to 12 Ultimate based on how much execute bonus damage it dealt.

### Pieces
The set consists of Two Handed melee weapons of all types.

### Notes
- While the description states that 2 items are required, this is because 2-handed weapons count as 2 items by themselves, so only 1 item is actually needed.
