# Online:Impregnable Armor

Source: https://en.uesp.net/wiki/Online:Impregnable_Armor
License: CC BY-SA, UESP

Impregnable Armor is an Battlegrounds Set rewarded by Battlegrounds. The light armor of this set can be obtained in boxes purchased using Alliance Points from the Cropsford Quartermaster. The medium armor of this set can be obtained in boxes purchased using Alliance Points from the Bruma Quartermaster. The heavy armor of this set can be obtained in boxes purchased using Alliance Points from the Vlastarus Quartermaster. It cannot be crafted and does not drop from monsters. Pieces are Militant Ordinator Style in all armor weights.

### Bonuses

2 items: Adds 9-424 Critical Resistance
3 items: Adds 9-424 Critical Resistance
4 items: Adds 9-424 Critical Resistance
5 items: Adds 22-986 Critical Resistance

### Pieces
The set consists of armor of all weights and jewelry in all slots, as well as weapons and shields of all types.
