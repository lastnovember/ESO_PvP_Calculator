# Online:Concentrated Force

Source: https://en.uesp.net/wiki/Online:Concentrated_Force
License: CC BY-SA, UESP

Concentrated Force is an Asylum Weapons item set which drops in normal Asylum Sanctorium after defeating Saint Olms the Just. It cannot be crafted. Pieces are Asylum Style. The perfected version of this set can be looted on veteran difficulty.

### Bonuses

2 items: Every second cast of Force Shock will always apply the Burning, Concussion, and Chilled status effects. The Force Shock casts must be made within 5 seconds of each other for this effect to occur.

### Pieces
The set consists of destruction staves of all three types.

### Notes
- While the description states that 2 items are required, this is because staves are 2-handed weapons, and thus count as 2 items by themselves, so only 1 item is actually needed.
- This set uses the following icon on your buff bar to track its stacks: Force Shock
