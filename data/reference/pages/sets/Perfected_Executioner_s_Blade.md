# Online:Perfected Executioner's Blade

Source: https://en.uesp.net/wiki/Online:Perfected_Executioner's_Blade
License: CC BY-SA, UESP

Perfected Executioner's Blade is a Perfected Vateshran Weapons item set which drops in veteran Vateshran Hollows. It cannot be crafted. Pieces are based on the Ancestral Reach Style. The non-perfected version of this set can be looted on normal difficulty.

### Bonuses

2 perfected items: Adds 12-526 Critical Chance
2 items: Hidden Blade deals up to 250% more damage to targets under 100% Health when you are standing behind them. Restores 1890 Stamina if the target was below 50% Health.

### Pieces
The set consists of one-handed weapons of all types. There is no shield.

## Notes
- You will always receive two weapons when this set drops, and they must be wielded together. If you use one with a shield or another weapon, it will not provide any bonus. You may, however, mix and match other items of this set found on subsequent runs of the trial.
