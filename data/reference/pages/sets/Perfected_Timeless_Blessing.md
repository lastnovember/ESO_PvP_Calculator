# Online:Perfected Timeless Blessing

Source: https://en.uesp.net/wiki/Online:Perfected_Timeless_Blessing
License: CC BY-SA, UESP

Perfected Timeless Blessing is an Perfected Asylum Weapons item set which drops in veteran Asylum Sanctorium after defeating Saint Olms the Just. It cannot be crafted. Pieces are Asylum Style. The non-perfected version of this set can be looted on normal difficulty.

### Bonuses

2 perfected items: Adds 20-877 Maximum Magicka
2 items: When you cast Blessing of Protection, the cost of your Magicka and Stamina healing abilities are reduced by 21% for 3 seconds.

### Pieces
The set consists of a restoration staff.

### Notes
- While the description states that 2 items are required, this is because staves are 2-handed weapons, and thus count as 2 items by themselves, so only 1 item is actually needed.
