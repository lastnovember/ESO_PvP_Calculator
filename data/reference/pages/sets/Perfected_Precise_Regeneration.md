# Online:Perfected Precise Regeneration

Source: https://en.uesp.net/wiki/Online:Perfected_Precise_Regeneration
License: CC BY-SA, UESP

Perfected Precise Regeneration is a Perfected Maelstrom Weapons item set found in veteran Maelstrom Arena. It cannot be crafted. Pieces are Maelstrom style. The non-perfected version of this set can be looted on normal difficulty.

### Bonuses

2 perfected items: Adds 12-526 Critical Chance
2 items: When your Regeneration critically strikes, you restore 12-558 Magicka. This effect cannot occur from simultaneous critical strikes.

### Pieces
The set consists of a restoration staff.

### Notes
- While the description states that 2 items are required, this is because staves are 2-handed weapons, and thus count as 2 items by themselves, so only 1 item is actually needed.
