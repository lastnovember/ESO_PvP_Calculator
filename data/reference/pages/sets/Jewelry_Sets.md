# Online:Jewelry Sets

Source: https://en.uesp.net/wiki/Online:Jewelry_Sets
License: CC BY-SA, UESP

Jewelry Sets are sets of jewelry and weapons that provide special bonuses to players when the items of the same set are equipped simultaneously. They do not include armor pieces other than shields. The way to obtain them depends on the type of the set.

## Level Up Advisor sets
These sets can be obtained through the Level Up Advisor.

Set Name | Bonuses

Broken Soul

Prophet's

## Trophy Vault sets
These sets are obtained as rewards from reward chests within Trophy Vaults in the Imperial City, or for completing a random group dungeon.

Set Name | Bonuses

Agility

Endurance

Willpower

## PvP Rewards
These sets have pieces that can be bought directly from Cyrodiil gear vendors using Alliance Points. These sets are also available via "Rewards for the Worthy" mails by participating in PvP, and in reward boxes for Cyrodiil dailies.

Set Name | Bonuses

Blessing of the Potentates

Eagle Eye

Grace of the Ancients

Vengeance Leech

Wrath of the Imperium

## First-Dungeons Dropped Sets
These sets were silently removed from the game with the One Tamriel Patch. It is believed they used to drop from the first dungeons (Banished Cells, Spindleclutch, Fungal Grotto, Wayrest Sewers, Elden Hollow, Darkshade Caverns), in veteran mode only.

Set Name | Bonuses

Arms of Infernace

Arms of the Ancestors

Relics of the Physician, Ansur

Relics of the Rebellion

The Destruction Suite

Treasures of the Earthforge
