This is the second incremental patch for Update 50 in The Elder Scrolls Online. This incremental addresses issues introduced during Update 50 launch and/or Season One launch.
In this update, you will see minor changes to Werewolf. Specifcally, to resolve some bugs impacting both visual and skill operation. We are also adjusting Feral Cruelty. In addition, we are addressing some visual fixes and system level fixes for Werewolf. Broader class adjustments will be reflected in later updates.
This update also addresses several base game issues. The Granny's Eel Pie recipe drops have been fixed and adjusted. Along with drop changes, there are several visual and UI fixes that are being addressed in today’s patch.
Lastly, we do have an additional test within the Vengeance Campaign stating later today. This will allow Item Sets to be tested in the Vengeance Campaign. We appreciate everyone taking the time to test things out. There is more specific info below for those interested.
The full list of patch notes is available below. Thanks, everyone!

Werewolf
Fixed an issue where some Werewolf effects could stack unintentionally in certain situations.
Updated the Werewolf introduction quest to grant temporary access to Gnash, Rending Claws, and Hircine’s Bounty, to give a better idea of the flow and experience of the Werewolf kit.
Feeding Frenzy: Fixed an issue where this synergy’s 6% damage bonus failed to properly apply the damage bonus.
Feral Cruelty: Reduced this bonus to 10|20% (5|10% against players) down from 12|25% (7|10% against players).
This change is to offset the damage bonus that will be seen with the Feeding Frenzy fix – which will still result in a buff when used in tandem.
Fixed the timing of the impact FX on Werewolf’s Bloodclaws ability.
Fixed the timing of the impact animations for Werewolf’s Rending Claws ability.
The audio for Werewolf’s light and heavy attacks should now play properly during the Werewolf introduction quest.
Vengeance Test the week of 7/20- 7/27
Item Sets are now enabled for testing in the Vengeance Campaign. This means the 5th piece bonus is the only thing active as we look at server performance with Item Sets Enabled. Stats from items’ 2-4 set bonuses are NOT active during this test (even though the UI displays them as enabled). During this time, Blackreach and Gray Host will be disabled unless it is determined that we need to turn them back on due to performance issues in Vengeance. For more info on this, please see
our forum post
from last week.
Gamepad UI
Practice Siege Repair Kits can now be added to quickslots while in Vengeance.
Zoning while viewing Veterancy will no longer disable Weapon Swapping.
One Handed Vengeance Weapon/Shields in Vengeance are available again to equip and use.
General
Jumping from an idle stance should no longer cause the elbow of your right arm to dislocate. (Does not apply to anyone 30 years old and up. Our joint pain is forever.)
Fixed an issue where certain unique personality animations were not playing properly.
Fixed a visual issue that occurred when previewing Style: Whirlwind, Spring Green.
The Tome-Bearer's Inspiration runes now appear correctly on the Apocryphabound weapon set.
General
Boundless Storm skill now makes the correct sound when casting.
Significantly increased the chance of looting a Breton themed furniture crafting recipe while in Rivenspire, Stormhaven, and Glenumbra to match other furnishing recipe drop rates.
Increased the chance of getting a new Ancient Summerset furniture crafting recipe in all the Summerset daily coffers.
Veterancy
Fixed an issue where Rewards for the Worthy containers from Veterancy were granting level 1 items, instead of scaling to your level.
Dynamic Events
Fixed an issue that prevented the Red Lichen ingredient and the Recipe for Granny's Eel Pie from having a chance to drop in the Bilsa's Delivery dynamic encounter in Stonefalls as intended. While still rare, the chance for the recipe to drop has also been increased.
General
Several U50 Collectibles no linger display the placeholder text "Template Description" instead of their properly localized collectible names.
Path to Adventure & Hero’s Return
Completing undaunted quests will now grant progress to the Golden Pursuit Campaign task "Complete Any Undaunted Quest".
General
Werewolf / Vampire: The repeatable Vampire and Werewolf introductory quests 'Hircine's Gift' and "Scion of the Blood Matron" are now able to be completed regardless if you'd previously finished the same quest by choosing to cure your affliction.

The Thieves Guild Returns: The Codex Caper
Fixed an issue with the Yveirry Estate gate that could make it very difficult to pass through after talking to Quen while on the quest “The Codex Caper.”
General
Chevalier's Honor Body Tattoo and Chevalier's Honor Face Tattoo no longer state they can be acquired through purchase, promotion, or event when viewed from the Collections menu.
General
Fixed a few issues with the animated background use on console and PC (while in gamepad mode) that could crash the client.
Fixed an issue in Spanish and Japanese where a UI Error would occur when using Controller Template C.
