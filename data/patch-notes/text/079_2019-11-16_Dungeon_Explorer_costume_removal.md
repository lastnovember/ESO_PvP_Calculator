We have temporarily removed the Dungeon Explorer costume from the Crown Store due to it being used with a certain combination of gear to exploit in PvP. We will be logging any account found to be exploiting this issue and appropriate action will be taken next week.
Just to update everyone on this situation, we just published a hotfix on all platforms that prohibits anyone who owns the Dungeon Explorer costume from equipping it. Note that we’re only temporarily disabling you from wearing the costume until we push out a more permanent fix, which will be coming in an upcoming incremental patch.
The fix for the Dungeon Explorer costume will be in Monday's PC incremental patch, so you'll be able to use the costume again at that point if you own it. We're also discussing when the costume will be back for sale, which is still TBD.
