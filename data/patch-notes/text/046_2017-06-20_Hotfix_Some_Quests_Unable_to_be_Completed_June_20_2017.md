We have completed a global hotfix on our PC/Mac servers to address an issue where some quests throughout the game were not able to be finished. As part of this fix, we have reverted the fix for the "A Cold Wind From the Mountain" quest. We will push a fix for that specific quest at a later date.
There is no patch to download for this hotfix.
Please note: If you had an active quest that you could not complete due to this issue, you will need to abandon the quest and pick it back up now that the hotfix is live.
