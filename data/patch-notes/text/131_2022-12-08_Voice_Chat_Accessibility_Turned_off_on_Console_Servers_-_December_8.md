This morning, we turned off Voice Chat Accessibility (speech-to-text) on our console servers to address a back-end issue with the feature. Players will still be able to toggle Voice Chat Accessibility on and off, but the system will not function while we have it turned off. We currently do not have an ETA for when we will turn Voice Chat Accessibility back on.
Please note that Narrate Chat (text-to-speech) is unaffected and still works.
Thank you for your patience. We will update this thread as we have more information.
