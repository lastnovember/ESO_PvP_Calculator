Xbox Patch Notes v1.26.3.0

Posted 2021-12-22 by ZOS_GinaBruno · forums.elderscrollsonline.com/en/discussion/594128 · archived 2026-09-12

The Elder Scrolls Online v1.26.3.0 fixes a crash that would occur when using certain combat abilities or firing ballistas. This is the same crash that would frequently result in a bluescreen error. The size of this patch is approximately 874.4 MB.
