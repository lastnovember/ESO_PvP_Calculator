Fix for Recent Issue with Character Stats

Posted 2017-02-20 by ZOS_GinaBruno · forums.elderscrollsonline.com/en/discussion/323483 · archived 2026-09-12
Hi everyone,

After today’s incremental patch on PC/Mac, we identified an issue where character stats were not properly scaling in certain zones. This was ultimately caused by a fix we implemented with today’s patch to address long loading screens in zones with high player density. At this time, we have reverted this fix. However, we have applied a temporary fix for the loading screen issue until we have a more solid fix for it.

If your character was affected by the original issue surrounding stats, you may have recently been logged off – this is expected. Once you log back in, your stats will properly scaled. None of these changes will require any downtime or patches to download.

Thank you!
