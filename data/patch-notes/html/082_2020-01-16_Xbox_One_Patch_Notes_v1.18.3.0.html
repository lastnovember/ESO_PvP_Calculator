Xbox One Patch Notes v1.18.3.0

Posted 2020-01-16 by ZOS_GinaBruno · forums.elderscrollsonline.com/en/discussion/508082 · archived 2026-09-12

The Elder Scrolls Online v1.18.3.0 includes several adjustments for the Activity Finder to improve its stability, in addition to further memory reductions to reduce game crash frequency. The size of this patch is approximately 642 MB.





General
  • Fixed an issue where you couldn’t select a guild to claim a Keep.

Battlegrounds
  • Fixed an issue where too many players could end up on one team in Battlegrounds.


General
  • Made further adjustments on the backend to reduce the chance of crashing in crowded areas.

Activity Finder
  • Improved the ability for the Dungeon Finder to handle a very high population of players.
  • Fixed some issues that could leave group members stuck in the queue.


Gamepad Mode
  • Fixed a UI error caused by attempting to purchase the latest chapter from the Crown Store.
