Xbox Patch Notes v1.27.1.0

Posted 2022-04-11 by ZOS_GinaBruno · forums.elderscrollsonline.com/en/discussion/602459 · archived 2026-09-12

The Elder Scrolls Online v1.27.1.0 fixes the issue where completed map POIs would sometimes appear incomplete, some issues with the Night’s Silence and Turning Tide item sets, a fix for your camera sometimes getting forced into first person view, and more. The size of this patch is approximately 1GB.





Quests
  • A Discreet Pickup: Fixed an issue where one of the Gleaner Drop Sites was extremely difficult to interact with.





Vateshran Hollows
  • Rahdgarak
    • Using the grappling hooks in this encounter will no longer cause your camera to point in odd directions.





Crafted Sets
  • Night’s Silence:
    • Fixed an issue where this set was not activating properly in many cases. 
    • This item set now works in “No Proc” Cyrodiil campaigns.

Dungeon Sets
  • Turning Tide: Fixed an issue where this set’s damage was not respecting its own cooldown. 





General
  • Added sound effects to the bird’s flapping wings when using the /feedbird emote.
  • Claiming a daily reward will now play the appropriate audio.


General
  • Fixed an issue where you could complete multiple Alchemy Crafting Writs per day on the same character.


General
  • Fixed a crash that could occur when first attempting to install the game.
  • Fixed an issue where the Ouroboros icon would appear every one second or so, spin for a moment, then disappear regardless of what you were doing in-game.
  • Fixed an issue where your camera would occasionally be forced into first person view.


Maps
  • Fixed issue where achievement related POIs, including delves, world bosses and dolmens, would sometimes incorrectly display as being incomplete on the map after first loading in.
