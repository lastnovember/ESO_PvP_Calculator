Xbox Patch Notes v1.30.1.0

Posted 2022-12-06 by ZOS_GinaBruno · forums.elderscrollsonline.com/en/discussion/623388 · archived 2026-09-12

The Elder Scrolls Online v1.30.1.0 contains several important fixes including a fix for block being cleared after dodge rolling or bashing, a fix for several Antiquity Leads that were not dropping, a number of quest fixes and crashes, a fix for Kjalnar's Mask Style Page not dropping, and more.

Please note there is a known issue involving block that most commonly occurs when attempting to swap weapons while weapons are being drawn or sheathed, preventing you from blocking again until zoning or relogging. This should be fixed in the next incremental patch.

The size of this patch is approximately 2.17GB for Xbox One and 1.1GB for Xbox Series X.

Quests
  • The Dark Aeon: Fixed issue where Joorahmaar could not be attacked after landing. 



General
  • Fixed an issue where several Druids were wearing the incorrect outfits.
  • Fixed an issue where the gold portions of the House Mornard Motifs would turn green if dyed blue.


General
  • Fixed an issue where petting a certain cow could give you meat, leather, or guts. It doesn’t work that way.


Furnishings
  • Fixed an issue where the “Firesong Spring, Basalt” achievement furnishing had incorrect visuals when viewed from very far away.
  • Updated a number of new craftable furnishings that you can sit on to have the appropriate “Sittable” tag in their tooltips.


General
  • Fixed an issue that would cause the delve boss of Embervine, Druid Rerlas, to not respawn after being defeated.


General
  • The door to Galen from Ivyhame no longer says “Ivyhame.”
  • Fixed an issue where you could not interact with the Vastyr Outskirts Wayshrine while standing in certain areas.
  • Fixed an issue where you would see a question mark instead of a highlight when targeting Galen from the Overworld map.

Quests
  • A Sea of Troubles:
    • Fixed an issue where there were two map pins for Dhulef on the step to talk to him.
    • Fixed an issue where you could not interact with Druid Laurel during the quest step to talk to her.
    • Fixed an issue where grouped players could become desynced and unable to complete the quest step "Investigate Tuinh Village".
  • A Heart Turned Black:
    • Fixed an issue where approaching a scene during this quest while in combat caused it to not advance until relogging.
    • Fixed an issue where Elder Pitof would sometimes not properly advance the quest after cleansing Bloated Muse-Mouths.
  • A Wailing Wood: Fixed an issue where relogging during the quest would cause prisoners to respawn after you had rescued them.
  • An Eye for an Eye: Fixed an issue where an interaction with a hiding spot would sometimes appear below ground.
  • Guardian of Y’ffelon: Druid Nhevin no longer pops between kneeling and standing when speaking to him.
  • Helpful Handbills: Fixed an issue where handbills were not properly aligned with the walls.
  • Shaky Job Prospects: Fixed an issue where Hierot could walk away from his initial conversation if spoken to quickly.
  • The Dream of Kasorayan: Fixed an issue where Druid Avien faced the wrong direction when discussing the stone tablet with Kasorayan’s final dream.
  • The Hidden Lord:
    • Fixed an issue where standing in a specific spot during the quest step “Search Knight Commander's Private Chamber” could cause the map compass icon to change rapidly.
    • Fixed an issue where the Garden Key was hidden beneath a rope when searching Garick’s Rest dungeons.
    • Fixed an issue where Druid Laurel would examine a rune-less column after declaring “Those carvings! Definitely druidic.”
  • The Ivy Throne:
    • Fixed an issue where you would sometimes not be ported out at the end of the quest.
    • Fixed an issue if your character died on the quest step “Return to Vastyr”, you would not be routed back to the correct location upon resurrecting.
    • Fixed an issue where Lady Arabelle Davaux’s stance was far too casual for someone in the heat of battle.
    • Fixed an issue where Lady Arabelle Davaux chose to walk through the surf instead of the sand when following you across the beach.
    • Fixed an issue where falling off the boat would not properly display how to get back on it.
    • The quest step for "Return to Castle Mornard" is now more specific to the location you need to go to.
    • Fixed an issue where many NPCs would speak regardless of which quest step you were on.
    • Fixed an issue where Druid Laurel would teleport oddly around the map when stuck.
    • Fixed an issue where story followers would stop following after death.
    • Fixed an issue where during the final quest, you could get into a non-stop deathloop (shoutout to Arkane Studios)
  • The Sea Runs Restless:
    • Fixed an issue where reading a note near Umindior before he asks you to read it could cause the quest to become stuck.
    • Fixed an issue where you could not talk to Quen after accepting the quest.
    • Fixed an issue where duplicate Quens could show up.
    • Fixed an issue where you can hear Umindior's torturous audio again by going backwards through the dungeon.
    • Fixed an issue where exiting the looting menu without collecting the quest item would cause Quen's dialogue to continue as if it were collected.
  • The Siege of Vastyr:
    • Fixed an issue where a scene with Stefan and Captain Siravaen would sometimes not trigger, causing the quest to not advance properly.
    • Fixed an issue where Stefan could start talking before your character loaded in.
