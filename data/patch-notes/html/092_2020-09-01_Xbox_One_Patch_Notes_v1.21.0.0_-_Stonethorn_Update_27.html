BASE GAME

Performance Improvements
  • Server Optimization & Stability
    • Through optimizations to database workers, the game’s access to the database has been refined to ensure the system does not become overloaded when part of it generates a large amount of traffic or messages for a particular task. The optimizations ensure that there are enough database workers focused on the highest-priority critical game functions.
    • Server performance has been improved in one of the least performant cases by distributing Trials more evenly across the system. This should ensure better overall performance in Trials, reducing the likelihood of getting a “bad instance” where enemies behave abnormally and latency is higher than normal.
  • Client Optimization & Stability
    • When using many different game assets, memory usage can spike and potentially get high enough to crash the game. We’ve made improvements to how the client handles these critical memory situations, better managing and prioritizing the most important elements in a scene. The chance that your game could crash in these situations has been significantly reduced.
    • Optimized the initial login flow; the time required to load when logging into character selection has been reduced.
    • Made some optimizations to reduce hitches when setting different outfits.

Character Pathing in Housing
You can now tell your pets, mounts, and assistants to follow custom paths in your home! This new functionality is available to everyone, regardless of DLC ownership or ESO Plus status.
  • To set up a path, first enter the housing editor and target a pet, mount, or assistant. You’ll see a new “Create Path” keybind; hit that to start making your path. Once selected, you’ll see a node underneath that character, and another node held in your hand like a furnishing.
    • You can use these nodes to mark the path you want that character to follow, and once you confirm your path edits, the character will immediately start walking down the path from node to node.
  • You can place up to 30 nodes per path.
  • You can also fine-tune your path with the following settings!
    • Movement speed to each node (Walk, Jog, Run, or Sprint)
    • Wait time at each node (0 seconds, 3 seconds, 10 seconds, 30 seconds, 1 minute, or 3 minutes)
    • Path type:
      • Ping Pong – The character will walk down the path until they hit the end, and then walk back to the beginning.
      • Loop – The last node in the path will be connected back to the first node, forming a circle.
      • Random – Each time the character reaches a node, they will choose their next location at random from the rest of the nodes in the path.
  • If you’d like to swap out the character on the path, no need to recreate the path from scratch – you’ll find a “Change Object” button in the Path Settings menu in each path, allowing you to swap in a new character from your collection.
  • As part of these changes, we’ve moved some keybinds that previously appeared at the bottom of the screen to the center of the screen near your targeting reticule, similar to where the interact prompt normally appears.

Spoiler
As part of the ongoing efforts to help improve performance, all item sets in the game have been updated to use better logic when attempting to determine their proc conditions with your actions, and will send significantly less messages to the server (ultimately being less taxing) when they fail to meet their conditions. We’ve also audited the vast majority of item sets in terms of their power, so make sure to check out the itemization section, and bring a snack!

In addition to item sets, many abilities have received backend improvements to their scripting to help reduce unnecessary effects, checks, and logic parsing, and will now more accurately follow their described behaviors, such as proc conditions.

We’ve also introduced some new Area of Effect (AoE) adjustments to the backend operations to help reduce their messaging and overall requirements to ping an area. Currently, we’ve only applied this to Dragonknight Standard and its morphs, as well as some monster abilities. We plan to monitor the overall improvements in a real combat environment, then slowly comb through old AoE abilities and apply the changes where applicable.

Spoiler
As mentioned in the intro, all item sets have been audited to reduce their implications on performance. Proc sets will no longer do additional range checks on events that already passed one (such as an event triggering off of a Light or Heavy Attack), will no longer send messages to the server when they fail or are on cooldown, and are properly labeled as a proc set to ensure they do not trigger other proc sets. During this audit, we have also brought almost every set in the game under our set bonus efficiency standard, which breaks down a set into its total worth of stats provided, plus modifiers such as how difficult or specific the set is to use/engage with! Due to the staggering size of this list, we’ve broken up the changes into more specific categories.

Additionally, we have adjusted all item sets that have radius checks for friendly targets to no longer target all allies, but instead target group members only.
