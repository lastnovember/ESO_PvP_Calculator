Xbox Patch Notes v1.40.2.0 | Update 46 Inc. 2

Posted 2025-07-23 by ZOS_Kevin · forums.elderscrollsonline.com/en/discussion/681038 · archived 2026-09-12

The Elder Scrolls Online v1.40.2.0 (Xbox) fixes issues identified post-Update 46 launch. The second incremental patch for Update 46 address issues in Solstice and Base Game zones. For Solstice, we’ve been working on fixes and adjustments to Ossein Cage and quest content. For Base Game, there are fixes ranging from minor visual errors, Console Addon tweaks, to UI fixes like adding the time column back for guild trader search.

You can find all patch notes for Update 46, Incremental 2 below. We will continue to monitor issues and update in later incremental patches.

Ossein Cage
  • Itemization & Item Sets
    • The final boss of Ossein Cage no longer unintentionally drops double loot.
  • Jynorah and Skorkhif
    • Made additional adjustments to the encounter visual effects to ensure they display properly.


World Boss
  • Tidewash Strand
    • Tidespite no longer randomly respawn during the encounter.


Ghosthunters
  • You are now able to consistently progress the quest when speaking to Valendir within the Reanimatorium.
The Gift of Death
  • You are now able to use the quick exit out of Corelanya Crypts.
The Stubbornness of Nords
  • Farmer Hrolf will no longer appear twice when leaving the area and returning.
Tales of Tribute
  • The Solstice Tribute daily now properly advances as intended.


General
  • Fixed an issue that caused certain effects to be invisible. You will now see Thieves Troves' glow behaves as it did previously.
  • Adjusted some wall collision to better fortify walls in Solstice. No more slipping behind walls!


General
  • Unintended sound effects on Time’s Herald weapon style have been removed and is no longer heard while stealthed.


Golden Pursuits
  • Endeavors and Golden Pursuit tasks for completing consumable and durable Master Writs now correctly categorize enchanting glyphs as a consumable product instead of a durable product.


Arx Corinium
  • Ganakton the Tempest
    • You can once again break free from Trapping Bolt.
    • Reduced the duration of Trapping Bolt and you can no longer be stunned by Lightning Split when affected by Trapping Bolt.


General
  • Fixed a rare crash that could occur when picking up housing decorations.
  • Xbox: Selecting an Xbox profile and immediately signing out no longer caused a crash.


General
  • Added Time column back in for gamepad guild trader search result.
  • The gamepad HUD Chat Display setting now updates the chat window immediately.
  • We have added more logging to better track the issues around Addon saving. (Amended Patch Note)
Console Addons
  • Installing a console addon now downloads all additional required addons needed or the main addon to work.
  • Addon fonts are no released from memory usage after they are loaded, now freeing up addon memory for other purposes.
